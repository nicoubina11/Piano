# 🎹 Piano Coach

App web para practicar piano: escalas con digitación, acordes con todas sus inversiones, progresiones, ejercicios de técnica y de ritmo, con detección por micrófono o teclado MIDI, misiones diarias, racha y logros.

Todo está en un único archivo: `index.html`.

## Uso
- Abrí `index.html` en el navegador, o publicalo (por ejemplo con GitHub Pages o Netlify) para usarlo desde el iPad.
- En iPad/iPhone: abrí la dirección en Safari → Compartir → **Agregar a pantalla de inicio**.
- El micrófono requiere una dirección `https`. MIDI funciona en Chrome o Edge (Safari no lo soporta).
